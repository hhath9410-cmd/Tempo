# Tempo

A standalone daily planner and habit tracker that works in a mobile browser.

## Use on iPhone

1. Open the repository's `index.html` through a hosted URL or download it and open it in Safari.
2. In Safari, tap **Share** and choose **Add to Home Screen**.
3. Add tasks as one-day tasks, daily habits, or weekly tasks.

The app is self-contained and requires no build step or dependencies.
